# 🍽️ MealFinder

Application mobile développée avec React Native et Expo.

## Fonctionnalités
- Navigation entre plusieurs écrans
- Liste des catégories de plats
- Filtrage par catégorie
- Recherche de plats par nom
- Détail complet d'une recette

## Technologies
- React Native
- Expo
- React Navigation
- TheMealDB API
